# Ngẫu nhiên cùng cô Thùy Tin

Web app chia nhóm ngẫu nhiên và chọn học sinh bằng trò chơi (Sói đuổi cừu, Đào vàng, Đua ong, Hứng trái cây, Thả zíc zắc).

Mở trực tiếp: https://ptn1095.github.io/ngaunhiencothuytin/

Toàn bộ ứng dụng nằm trong một tệp `index.html`, có thể tải về và mở bằng trình duyệt.
